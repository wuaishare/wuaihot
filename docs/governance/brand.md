# wuaihot 品牌基线

## 核心标识

- 英文项目名：wuaihot
- 中文品牌名：吾爱热榜
- 推荐组合：wuaihot · 吾爱热榜
- Slogan：一站看全网
- 官方示例站：https://hot.wuaishare.cn/

对中文用户界面，优先展示“吾爱热榜”；仓库、包名、技术标识与国际化语境优先使用 wuaihot。

## 图标

当前品牌图标位于：

- public/ico/wuaihot.svg：矢量主标（以 v1-smooth 为当前 canonical 展示版本）
- public/ico/favicon.png：兼容 favicon / PWA 的 PNG
- public/favicon.svg、public/favicon.png：根目录兼容资源

图形以 **W + 上升趋势** 为核心语义，避免继续沿用 DailyHot 的原品牌识别。

## 文案原则

产品定位优先使用“今日热榜、全网热搜、实时热点、跨平台趋势榜单”等用户可理解的关键词，不堆砌无意义 SEO 词。

品牌主张保持简短：**一站看全网**。
