# 数据与内容治理边界

wuaihot 是开源软件项目，不是第三方平台数据权利的再许可方。

## 代码与第三方内容分离

MIT License 适用于本仓库中依法可授权的原创代码与相关内容。第三方平台的数据、文章、图片、视频、用户内容、商标、Logo 与接口响应仍受各自权利、平台条款与适用法律约束。

仓库不应打包可替代原平台的大规模历史数据镜像、第三方内容数据库或需要私密凭据才能获得的数据快照。

## 数据源治理原则

不同数据源应分别评估：

1. 数据获取方式是否允许；
2. 公开页面展示是否适合；
3. 匿名机器可读 Public Feed 是否适合；
4. 商业 API、批量导出或再销售是否需要额外授权。

“页面公开可见”不自动等于“允许任意自动采集、批量再分发或商业 API 转售”；反过来，平台限制自动化获取也不应被机械解释为对所有事实数据的永久排他权。

## 项目默认边界

- 优先官方开放 API、RSS、明确开放许可或已获授权的数据源；
- 不提供验证码绕过、登录绕过、签名破解、设备指纹规避或其他反技术措施代码；
- 对需要审查的数据源采用最小必要展示、明确来源与原文链接；
- Public Feed 与商业 API 使用独立准入规则，不因前端可展示而自动开放；
- 第三方 Logo 仅用于来源识别，不表示平台对 wuaihot 的认可、合作或授权。

部署者应根据自己的数据来源、地区与使用场景独立确认合规要求。
